## 🧩 About

**Squad overlay** is a curated list of Squad open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD reference, map overlay notes
- **Quality-of-Life Helpers** — loadout catalog, config manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Match Helpers
- Map Overlay Notes — review tactical layouts in single-player study
- HUD Reference — visualize status panels and team info
- Replay Notes — record and review offline match runs
- Playback Speed — adjust demo playback for study (0.1x to 5x)

### 🎨 Loadout & Cosmetics
- Loadout Catalog — browse kits, roles, and camo notes
- Custom Preset Notes — organize player configs
- Visibility Notes — improved readability of on-screen elements

### 🏋️ Practice Layout
- Training Mode Notes — segment study on any layout
- Stance Control Notes — reference switching stances in the editor
- Movement Buffer Notes — chain complex maneuvers in practice maps
